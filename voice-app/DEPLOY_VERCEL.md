# Luna · публикация сайта на Vercel

Luna — статический сайт (`public/index.html`, CSS, JS), совместимый с Vercel. Ни Android, ни npm-сборка для публикации сайта не требуются.

1. В Vercel выберите **Add New → Project** и импортируйте GitHub-репозиторий `dednain/gestalt-net`.
2. **Root Directory:** `voice-app` (этот каталог). **Framework Preset:** `Other`. **Output Directory:** `public`; `vercel.json` уже настроен.
3. Поскольку изменения находятся в изолированной ветке `feature/luna-voice-android`, выберите её в **Settings → Git → Production Branch** и задеплойте эту ветку (или сначала слейте PR после проверки).
4. На Vercel после деплоя будет доступен **интерфейс сайта** по HTTPS, установка на главный экран через PWA тоже возможна.
5. Для реальной голосовой связи нужен отдельный доступный пользователям WebSocket-сервер и TURN (развёртывание — в `README.md` и `deploy/`). При наличии WSS-адреса укажите его в настройках сайта либо отредактируйте `public/config.js` и заново задеплойте. **Не помещайте секреты или TURN_SECRET в config.js:** это публичный файл.

Сервер `server.js` хранит комнаты в оперативной памяти и не предназначен для многократных экземпляров Vercel Functions. Vercel теперь поддерживает WebSocket Functions, но для масштабирования потребуется вынести состояние комнат в Redis или аналогичную систему. Чтобы не выдавать случайные потери связи за готовый продукт, текущая конфигурация Vercel деплоит только фронтенд.

Важно: размещение на Vercel само по себе **не гарантирует** доступность без VPN в России. Проверьте сайт, WSS и TURN на мобильных операторах. Пока WSS не настроен, сайт честно показывает «Нужен сервер».
