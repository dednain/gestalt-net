# Luna · сайт голосовых комнат

**Сначала сайт на Vercel, затем Android-приложение.** Интерфейс адаптирован для телефона. Включает создание/вход в комнату по коду, управление микрофоном, прослушиванием и полным мутом, список участников и приглашение по ссылке. Фронтенд — статический, готов к Vercel. [Инструкция по Vercel](DEPLOY_VERCEL.md).


Современное мобильное приложение с WebRTC: голос в реальном времени, комнаты по шестизначному коду, 6 участников в комнате (P2P mesh), микрофон **вкл/выкл**, режим **слушать / отключить звук**, **полный мут**, громкость, приглашение по ссылке, PWA и будущий Android APK через Capacitor.

## Что реально готово

- Сервер сигнализации WebSocket `/signal`, проверка комнат и пересылка WebRTC SDP/ICE.
- WebRTC аудио: шифрование DTLS-SRTP по умолчанию, echo cancellation, noise suppression; аудио передаётся между телефонами, а не через signaling-сервер.
- Самостоятельный TURN через coturn (включается при деплое) с краткоживущими HMAC-учётными данными.
- Мобильный веб-интерфейс, который можно добавить на домашний экран; Capacitor APK собирается GitHub Actions.
- Без регистрации и аналитики. Код комнаты — единственная «защита» комнаты; не предназначен для конфиденциальных звонков или больших групп без усиления безопасности.

## Запуск локально

```bash
cd voice-app
npm install
npm start
```

Откройте `http://localhost:3000` в Chrome на компьютере. Микрофон через браузер доступен на `localhost` или **HTTPS**. Для настоящих телефонов через интернет нужен публичный HTTPS домен, WSS и TURN (ниже). Локальный `http://192.168...` на телефоне обычно НЕ имеет доступа к микрофону.

## Развёртывание для пользователей в России

1. Возьмите VPS с публичным IPv4 и маршрутизацией, доступной из России, и домен. В DNS создайте `A`-запись на публичный IP. **Размещение сервера за границей не гарантирует доступ без VPN**; проверяйте конкретного провайдера и сеть.
2. Скопируйте `deploy/.env.example` в `deploy/.env`, укажите `VOICE_DOMAIN`, `PUBLIC_IP`, случайный `TURN_SECRET` (`openssl rand -hex 32`). Никогда не коммитьте `.env`.
3. Откройте входящие порты TCP 80/443, TCP и UDP 3478 и UDP 49160–49200; DNS и TLS по 443 должны работать с мобильных операторов. Docker Compose выдаёт HTTPS через Caddy и запускает coturn.
4. Запустите в корне `voice-app`: `docker compose --env-file deploy/.env -f deploy/compose.yml up -d --build`.
5. На двух разных телефонах зайдите в `https://ВАШ_ДОМЕН`, создайте комнату, дайте код другу, включите микрофоны и проверьте слышимость с мобильным интернетом разных операторов. **Без настоящего VPS проверить отсутствие необходимости VPN нельзя**.

Сервер генерирует TURN HMAC доступ на один час через `TURN_SECRET`. Дополнительно рекомендуется TURN/TLS по TCP 443 на отдельном IP или хосте для сетей, блокирующих UDP/3478; в текущем примере он не настроен. Для продакшена добавьте авторизацию, rate limiting на прокси, безопасные TURN-правила, логи и мониторинг.

## APK через GitHub

Workflow находится в корне репозитория: `.github/workflows/luna-voice-apk.yml`. При push в ветку `feature/luna-voice-android` или ручном запуске GitHub Actions:

1. Устанавливает Node 22, JDK 21 и Android SDK.
2. Создаёт Android-проект Capacitor, включает `RECORD_AUDIO` и `MODIFY_AUDIO_SETTINGS` в `AndroidManifest.xml`.
3. Собирает **debug APK** и выкладывает в артефакт `luna-voice-android-debug`.

APK при первом старте попросит **Настройки → Сервер сигнализации**: `wss://ВАШ_ДОМЕН/signal`. Это нужно потому, что адрес VPS пока неизвестен. После указания WSS войдите в комнату. Для установки APK разрешите установку из выбранного источника и выдайте доступ к микрофону при нажатии на кнопку.

**Ограничения MVP:** без работающего VPS, HTTPS/WSS и TURN реальная связь через интернет не гарантируется; без запуска CI APK пока не существует; WebRTC mesh до 6 человек больше нагружает слабые телефоны, чем SFU; работа в фоне при заблокированном телефоне пока не реализована; debug APK не является подписанным релизом для Google Play.

## Архитектура

```text
Android APK (Capacitor WebView) / Chrome PWA
      │ WSS                  ┌─ TURN (coturn, HMAC)
      ├── signaling server ──┤
      │                      └─ WebRTC ICE negotiation
      └───── encrypted P2P audio / TURN relay ───── другие телефоны
```

Пользователи выбирают микрофон и прослушивание **независимо**; полный мут временно отключает и то, и другое. Выключение микрофона останавливает захват аудио устройством.


> Состояние проекта: сборка интерфейса не означает, что голос на двух реальных устройствах уже проверен. Для разговоров по сети требуется развёрнутый WSS/TURN; APK откладываем до завершения сайта.
